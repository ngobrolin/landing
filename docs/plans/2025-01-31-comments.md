# Comments Feature Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add GitHub Issues-based comments to episode pages using utterances widget.

**Architecture:** A new Comments component injects the utterances script, which maps each episode URL to a GitHub issue. Comments are stored as labeled issues in the repo.

**Tech Stack:** Astro (SSG), utterances (GitHub Issues-based commenting), Playwright (E2E testing)

---

## Task 1: Create the Comments Component

**Files:**
- Create: `src/components/Comments.astro`

**Context:** This component renders the utterances comment widget. It uses a client-side script to load utterances, which automatically creates/fetches GitHub issues based on the page URL.

**Step 1: Create the Comments component**

Create `src/components/Comments.astro` with the following content:

```astro
---
// Comments.astro - Utterances comment widget component
// No props needed - utterances uses page URL for issue mapping
---

<section class="mt-12 pt-8 border-t border-dark-border">
  <h2 class="text-xl font-bold text-white mb-6">Komentar</h2>
  <div id="comments-wrapper">
    <!-- Utterances will inject the comment widget here -->
  </div>
</section>

<script>
  // Load utterances script client-side
  // This script runs after the page loads and injects the comment widget
  const utterancesScript = document.createElement('script');
  utterancesScript.src = 'https://utteranc.es/client.js';
  utterancesScript.async = true;
  utterancesScript.crossOrigin = 'anonymous';

  // Utterances configuration
  utterancesScript.setAttribute('repo', 'ngobrolin/landing');
  utterancesScript.setAttribute('issue-term', 'pathname');
  utterancesScript.setAttribute('label', 'comment');
  utterancesScript.setAttribute('theme', 'preferred-color-scheme');
  utterancesScript.setAttribute('crossorigin', 'anonymous');

  // Inject script into the comments wrapper
  const commentsWrapper = document.getElementById('comments-wrapper');
  if (commentsWrapper) {
    commentsWrapper.appendChild(utterancesScript);
  }
</script>
```

Expected: File exists at `src/components/Comments.astro`

**Step 3: Commit**

## Task 3: Create E2E Tests

**Files:**
- Create: `e2e/comments.spec.ts`

**Context:** These tests verify that the comments section appears on episode pages and the utterances script loads correctly.

**Step 1: Create the E2E test file**

Create `e2e/comments.spec.ts` with the following content:

```typescript
import { test, expect } from '@playwright/test';

test.describe('Comments Section', () => {
  test('comments section is displayed on episode page', async ({ page }) => {
    await page.goto('/');
    const firstEpisode = page.locator('[data-testid="episode-card"]').first();
    await firstEpisode.click();

    await expect(page.getByRole('heading', { name: 'Komentar' })).toBeVisible();
  });

  test('utterances script is loaded', async ({ page }) => {
    await page.goto('/');
    const firstEpisode = page.locator('[data-testid="episode-card"]').first();
    await firstEpisode.click();

    // Check that utterances iframe is present (utterances loads as an iframe)
    const utterancesIframe = page.locator('iframe.utterances');
    await expect(utterancesIframe).toBeVisible();
  });

  test('comments section appears before navigation', async ({ page }) => {
    await page.goto('/');
    const firstEpisode = page.locator('[data-testid="episode-card"]').first();
    await firstEpisode.click();

    // Comments section should be visible
    const commentsSection = page.getByRole('heading', { name: 'Komentar' });
    await expect(commentsSection).toBeVisible();

    // Navigation should appear after comments
    const navText = page.getByText('Episode Selanjutnya');
    const commentsBox = await commentsSection.boundingBox();
    const navBox = await navText.boundingBox();

    expect(commentsBox.y).toBeLessThan(navBox.y);
  });
});
```
